Form de serviço

Modal centralizado sobre a tabela de serviços. Chips de profissional com avatar ring (clicáveis pra remover). Preço/duração em JetBrains Mono pra tabular numbers. Toggle "Ativo" embaixo com explicação inline do impacto.

  • Server Action: roleCheck OWNER, Zod parse, withTenant, revalidatePath

W-15 · Modal Novo Agendamento

Encaixe manual

Botão "+ Novo agendamento" no dashboard (W-07) e na agenda (W-08) abrem esse modal. O dono cria agendamento sem passar pelo fluxo do cliente — útil pra encaixes, atendimento por telefone, retorno fidelizado.

  • Cliente: autocomplete busca clientes existentes ou cadastra novo inline
  • Anti-conflito: calcula slot disponível em tempo real (mesmo algoritmo PBI-06) e mostra confirmação verde
  • Bypass: dono pode forçar mesmo com conflito (flag `force=true` na Server Action) — útil pra overbook
W-16 · Modal Cancelar

Cancelar com motivo

Botão "Cancelar" no drawer (W-13) abre esse modal de confirmação. Motivo é obrigatório (vira métrica de churn). Notificação por email é opcional — dono pode silenciar se já avisou pelo WhatsApp.

  • RN-07: Cancelamento em até 2h antes (configurável) — depois disso, vira no-show
  • Append-only: status muda pra `CANCELLED` + adiciona `cancellationReason` + `cancelledAt` (não deleta)
  • Slot livre: EXCLUDE constraint deixa de bloquear o horário — outro cliente pode pegar

11 · Estados

Empty, loading, erro.

A maior parte do trabalho em UI mora aqui — nas bordas. Sem agendamentos? Sem serviços cadastrados? Slot ocupou? Email inválido? Cada estado tem uma cara própria, sem genérico.

Empty

Nenhum serviço ainda

Cadastre seu primeiro serviço (ex: Corte) pra começar a receber agendamentos.

Empty

Sem agendamentos hoje

Aproveita pra atualizar serviços ou compartilhar o link da sua agenda.

Loading · skeleton

Erro perto do campo. Sem toast genérico.

14 · Motion

Animação só onde ela ajuda.

Microanimações pra dar feedback (chip pressionado, card hover, fade-up). Animações grandes só pra momentos especiais: o checkmark da confirmação. Tudo respeitando prefers-reduced-motion.

Lib recomendada

motion/react

Sucessora do Framer Motion. ~30kb gzipped. Excelente DX, suporta layout animations e transitions baseadas em scroll.

pnpm add motion
Complementares

tailwindcss-animate

Utilitários CSS pra fade/slide/zoom sem JS. Já está no projeto. Usar pra transições simples.

animate-in fade-in-50
Nativo

View Transitions API

Transições entre rotas no Next.js 15. Sem JS extra. Ideal pra fluxo cliente (1 → 2 → 3 → 4).

unstable_ViewTransition
